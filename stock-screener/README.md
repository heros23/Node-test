# KOSPI/KOSDAQ/NASDAQ 4대 기법 실시간 검색기

기존 `toss-envelope-bot` 프로젝트를 제거하고, KOSPI/KOSDAQ/NASDAQ 종목을 대상으로 4대 단기 매매 기법(256, 밥그릇 3번, 공구리, 오돌이) 조건을 실시간(폴링)으로 검색하는 새로운 시스템입니다.

## 4대 기법 조건식

### 1. 256 기법
- A: 5/20/60일 이평이 3% 이내 밀집
- B: 종가 5이평 > 종가 20이평
- C: 종가 6이평 > 종가 20이평
- D: 당일 거래량이 전일 거래량 대비 200% 이상 증가
- 조합: A AND B AND C AND D

### 2. 밥그릇 3번 (낙폭과대 반등)
- A: 100영업일 전 종가 > 당일 종가 (하락추세 확인)
- B: 종가가 112일 이평선 골든크로스
- C: 종가가 224일 이평선 골든크로스
- D: 5이평 > 20이평 > 60이평 정배열
- 조합: A AND (B OR C) AND D

### 3. 공구리 기법 (지지막 돌파)
- A: 최근 5봉 중 당일 종가가 가장 높음 (신고가)
- B: 종가가 20일 이평선 골든크로스
- C: 볼린저 밴드 상한선 이상 종가
- D: 일목균형표 선행스팬1, 2 위에 주가 위치
- 조합: A AND B AND C AND D

### 4. 오돌이 기법 (키움 0150 기준)
- A: 20이평 > 60이평 > 112이평 (또는 224이평 위에 주가 위치)
- B: 5봉 내 최고종가 대비 최저종가 하락률 -5% 이상
- C: 5이평 1봉전 하락추세 지속 -> 0봉전 상승전환
- D: 종가 1이평(당일 종가)이 종가 5이평을 골든크로스
- E: 당일 거래량 > 전일 거래량 150% 이상 증가
- 조합: A AND B AND C AND D AND E

## 제외 종목 (대상 변경)
- 관리종목, 투자경고/위험, 우선주, ETF, ETN, 정리매매, 스팩(SPAC), 초저유동성종목

## 데이터 소스
- KOSPI/KOSDAQ: pykrx (KRX 데이터, 무료, 지연)
- NASDAQ: yfinance (Yahoo Finance, 무료, 지연)
- 실시간 효과: 60초 폴링 + WebSocket 브로드캐스트
- 일봉 데이터는 `data/cache/`에 parquet로 캐싱 (24시간 기준)

## 실행 방법

```bash
cd /home/user/webapp/stock-screener
pip install -r requirements.txt
python run.py
```

서버가 `http://0.0.0.0:8080`에서 시작됩니다. 웹 브라우저에서 대시보드 확인 가능합니다.

## API
- `GET /` - 웹 대시보드
- `GET /api/status` - 서버 상태 및 종목 수
- `GET /api/signals` - 전체 신호 목록
- `GET /api/signals?strategy=256 기법&market=KOSPI` - 필터링 신호
- `GET /api/strategies` - 기법 설명
- `WS /ws` - 실시간 신호 WebSocket
